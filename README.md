The funniest one-line error message an AI agent shows when it runs out of tokens mid-sentence: `Error: out of tokens. The sentence was about to get really good, and now neither of us will ever know how it ends.` — 114 characters, one line, nothing else.

## Run it

```sh
python3 main.py
```

That writes the entry to `/output/entry.txt` and prints exactly the one line. Run `python3 main.py --self-test` to verify the output is byte-identical across runs and passes the bounty gate (1–140 characters, single line, not only whitespace).
